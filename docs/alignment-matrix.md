# مصفوفة المواءمة: الوحدة والشاشة والناتج والنشاط والتقويم والبيانات

المرجع: وثيقة التصميم التعليمي والسيناريو التفصيلي، الإصدار 0.1 (23 أكتوبر 2026). الرموز: ن للناتج، ت لعنصر الاستكمال، س للشاشة.

نوع التقويم في العمود الخامس أحد أربعة أنواع لا يُخلط بينها في الواجهة ولا في الحساب:

- **آلي مغلق**: بند له مفتاح، يُصحح آليًا.
- **اكتمال حقول**: يفحص النظام وجود الإدخال فقط، ولا يحكم على جودته.
- **مراجعة ذاتية**: يختار المعلم وصفًا أو يجيب عن أسئلة مراجعة؛ لا يُحوَّل إلى درجة.
- **دليل تطبيق**: سجل ما حدث فعلًا أو محاكاة موسومة؛ لا يُشترط للاجتياز.
