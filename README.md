# bloom-digital-report

حقيبة هرم بلوم الرقمية: برنامج تعلم ذاتي لمعلمي التعليم العام (موقع ثابت على GitHub Pages).

- التشغيل: افتح `index.html` في المتصفح، أو شغّل `python -m http.server` وافتح `http://localhost:8000`.
- الاختبارات: `npm test` (حساب الاجتياز والتخزين والترحيل). فحوص المتصفح الاختيارية في `tests/e2e/`.
- سجل التنفيذ والقرارات المعلقة: `docs/implementation-log.md`. مصفوفة المواءمة: `docs/alignment-matrix.md`.
- تعليمات العمل على المشروع: `CLAUDE.md`.
